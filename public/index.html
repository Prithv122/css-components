CSS Components

Buttons, cards, forms, and a modal — every interaction on this page, including the modal opening and closing, runs on CSS alone. No <script> tag anywhere in this document.

Buttons

Four variants, two extra sizes, and disabled state — all built on one .btn base class.

Cards

A media block, body content, and an actions row. Hover to see the elevation change.

Elevated card

Default shadow that deepens on hover, with a lift via transform.

Flat card

Same markup, .card-flat drops the resting shadow for a quieter list.

Forms

Text inputs, a select, a textarea, checkboxes/radios, and a live validation state — try leaving the email field blank and clicking away, or typing something without an @.

Modal

Opened and closed entirely with the checkbox hack — a hidden, still-focusable checkbox toggled by <label for> controls, styled with :checked ~ and animated with @starting-style. See the README for what this pattern trades away.
